# 介護の予定帳（PWA）

iPhoneで使う、自分専用の介護の予定帳です。**1日の流れ（出発 → 出勤 → 予定・休憩 → 退勤）** と、各予定の利用者さん・内容がひと目でわかることに絞っています。勤務時間の記録や残業の計算はありません。

- HTML / CSS / JavaScript だけで動作（サーバー・ログイン・外部DBなし）
- データは **iPhone内のIndexedDB** にだけ保存（どこにも送信しません）
- Safariの「ホーム画面に追加」でアプリとして起動、**オフラインでも動作**
- ダークモード対応・大きめの文字・片手で押しやすいボタン

## 画面と機能

| 画面 | 内容 |
|---|---|
| 予定 | その日の流れを時間順に大きく表示：いちばん上に **出発**（出勤の1時間30分前、設定で変更可）、**出勤**、予定と **休憩**、最後に **退勤**。各予定に **時間・利用者さん（苗字と町）・内容（入浴／移動支援／その他）・水着あり**・メモ・その方の介助ポイントを表示。‹ › で前後の日へ移動。「今日」「明日」表示つき。時間が重なる予定は赤枠で注意 |
| カレンダー | 予定のある日に内容別の色の点（青＝入浴、緑＝移動支援、灰＝その他）と「水」マーク（水着ありの入浴がある日）、出勤時刻。日付をタップするとその日の予定へ。月ごとの件数（内容別・水着あり） |
| 利用者 | 苗字（表示用）・フルネーム・住所の町・入浴介助の水着（いる／いらない／未確認）・内容（介助のポイント）を記録。名前や町で検索、「水着いる」「水着未確認」で絞り込み |
| 設定 | 出発を出勤の何分前にするか（初期値90分）、テーマ、CSVバックアップ、全データ削除 |

### 予定の入れ方

0. 「出勤・休憩・退勤を入力」で、その日の出勤時刻・休憩・退勤時刻を入れる（出発時刻は自動で表示。新しい日は前回入れた時刻が最初から入ります）。出発・出勤・休憩・退勤の行をタップしても変更できます。
1. 「予定」画面で日付を選び「＋ 予定を追加」。
2. 開始時刻（終了は任意）、利用者さん、内容（入浴／移動支援／その他）を選ぶ。
3. 入浴を選ぶと「水着あり／なし」が出ます。利用者さんを「水着いる」で登録していれば自動で「水着あり」になります。
4. 利用者さんを選ぶと、フルネーム・町・水着・内容がその場で見られます。「利用者の情報を変更」から書き換えもできます。まだ登録されていなければ、選択欄の「＋ 新しい利用者を登録…」からその場で登録できます。
5. 毎週同じ予定は、予定を開いて「コピーして別の日に追加」（1週間後の日付が入ります）。
6. 保存・削除の直後は、お知らせの「取り消す」で元に戻せます。

### 利用者さんの情報について

- 予定や一覧には苗字（と町）だけを表示し、フルネームは利用者の画面と予定を開いたときだけ表示します。
- 住所は **町名まで** にしてください。番地・建物名・部屋番号・生年月日・病名などは入力しないでください。
- データはこのiPhoneの中にだけ保存され、外部には送信されません。iPhoneにはパスコード（Face ID）を必ず設定してください。
- バックアップのCSVには利用者さんの苗字・フルネーム・町名・内容が入ります。メールやLINEで送らず、iPhoneの「ファイル」アプリなど自分だけが見られる場所に保存してください。
- 勤め先に「利用者情報を私物のスマホに保存しない」などの決まりがある場合は、そちらに従ってください。
- 利用者さんを削除しても、過去の予定には苗字だけが残ります。

## GitHub Pagesでの公開手順（最初の1回だけ）

1. GitHubでこのリポジトリを開き、**Settings → Pages** を開く。
2. **Build and deployment → Source** を **「Deploy from a branch」** にする。
3. **Branch** で `main` と `/ (root)` を選び、**Save** を押す。
4. 1〜2分待ってから上の公開URLを開く。以降は `main` を更新するたびに自動で公開されます。

> **注意**
> - 公開されるのはアプリのプログラムだけです。**予定や利用者のデータはiPhone内にしか保存されない**ので、URLを他人が開いてもあなたの記録は見えません。
> - アプリを修正したときは `sw.js` の `CACHE_VERSION` を上げてください。iPhone側で次に開いたとき新しい版に入れ替わります（「アプリを更新しました」と表示されます）。

### パソコンで試す場合

```
npx http-server . -p 8080
```

`http://localhost:8080/` を開きます（Service Workerは `file://` では動かないため、必ずサーバー経由で開いてください）。

## iPhone（Safari）での動作確認手順

1. **Safariで公開URLを開く**（Chromeなど他のブラウザでは「ホーム画面に追加」してもオフライン動作が不安定です）。
2. 画面下の **共有ボタン（□に↑）→「ホーム画面に追加」** →「追加」。ホーム画面に「予定帳」アイコンができます。
3. **ホーム画面の「予定帳」アイコンから起動** し、上部にSafariのアドレスバーが出ない（アプリとして全画面で開く）ことを確認。
   - ⚠️ Safariのタブで開いたときと、ホーム画面から開いたときは **データが別々** です。記録は必ずホーム画面のアイコンから行ってください。
4. **利用者の登録**：利用者タブの「＋ 追加」で苗字・フルネーム・町・水着（いる）・内容を登録。町名で検索できることも確認。
4-2. **出勤・休憩・退勤**：予定タブの「出勤・休憩・退勤を入力」で出勤8:30などを入れ、いちばん上に「出発 7:00（出勤の1:30前）」が出ること、休憩が予定の間に、退勤が最後に並ぶことを確認。
5. **予定の追加**：予定タブ →「＋ 予定を追加」→ 開始時刻・利用者・「入浴」を選ぶ → 水着が自動で「水着あり」になることを確認して保存。予定に「水着あり」とその方の内容が表示されればOK。予定を開き、フルネーム・町が見えること、「利用者の情報を変更」で書き換えられることも確認。
6. **移動支援・その他**：同じ日に「移動支援」「その他」の予定も入れ、時間順に並ぶこと、移動支援では水着の欄が出ないことを確認。
7. **修正・コピー・取り消し**：予定をタップして時刻を変える／「コピーして別の日に追加」で翌週に入る／保存後の「取り消す」で元に戻ることを確認。
8. **カレンダー**：色の点と「水」マーク、月の件数を確認。日付をタップするとその日の予定が開くことを確認。
9. **ダークモード**：iPhoneの「設定 → 画面表示と明るさ」でダークに切り替え、アプリも暗い表示になることを確認（アプリの設定画面でライト/ダーク固定も可）。
10. **オフライン**：一度アプリを開いた後、**機内モード** にしてアプリを完全に閉じ（アプリスイッチャーで上にスワイプ）、再度ホーム画面から起動。普通に開いて入力できればOK。
11. **バックアップ**：設定 →「CSVで書き出す」→ 共有シートで **「"ファイル"に保存」**。次に「CSVを読み込む」でそのファイルを選び、件数の確認が出て読み込めることを確認。

## データを守るために

- iPhoneの故障・機種変更・アプリの削除でデータは消えます。**月に1回はCSVを書き出して**「ファイル」アプリ（iCloud Drive）などに保存してください。30日以上書き出していないと、ホーム画面に案内が表示されます。
- ホーム画面のアイコンを削除すると、そのアプリのデータも消えます。
- CSVはExcel・Numbersでも開けます（`kind` は bath=入浴 / move=移動支援 / other=その他、予定の `swimsuit` は 1=水着あり）。
